# Agent instructions

The instructions for agents are the skill **`skills/search-hub/SKILL.md`**: when to search, how to read pages with
`question`, how to check sources and answer, plus HTTP recipes for agents without the MCP tools.

- Claude Code / Codex: copy it to `~/.claude/skills/search-hub/SKILL.md` and `~/.codex/skills/search-hub/SKILL.md`
  (see `docs/CLIENTS.md`, step 4).
- Other agents: paste the body of `SKILL.md` (everything after the `---` header) into the agent's instructions.
